2. Anomaly check via parsing eval
This feature should now be treated as a Python-side anomaly detector over Alexander trace text, not as an engine-core modification, because Alexander already exposes parseable textual evaluation fields such as final evaluation, Shashin zone, game phase, mobility by area, space by area, weak squares, and Makogonov activity summaries. That makes the work low-risk and consistent with ShashChimera’s existing pattern of parsing engine output into structured boundary objects before prompt assembly.
What to implement
Create a dedicated module such as alexander_anomaly_detector.py.
Split the work into:
parse_eval_text(text) -> EvalSnapshot
detect_anomalies(snapshot) -> list[str]
Parse the already available Alexander trace fields into a dataclass:
eval_cp
win_prob
shashin_zone
game_phase
mobility
space
weak_squares
worst_piece
ranking
Then derive anomaly tags such as:
mobility_deficit_center
space_collapse_queenside
too_many_weak_squares_black
major_piece_restricted_white
zone_score_contradiction
How to use it
Add anomaly tags to the retrieval query, not just to the prompt.
Example: if anomaly says worst_piece_knight_low_activity, append tokens like passive piece, improve worst piece, piece coordination, maneuvering.
Also add a compact summary line in the prompt:
Structural alerts: White is cramped on the queenside and has many weak dark squares.
Important constraint
Keep the anomaly summary compressed to one line or two bullet points, because the prompt budget is intentionally tight for sub-1B models.
Expected impact
This should improve completeness and specificity, because the model will receive structured positional defects that are often invisible from the centipawn number alone.

Here is the complete **pure text-parsing anomaly detector** — no C++ changes to Alexander. It works entirely on the eval string output that `trace_analysis()` already produces.

## What the eval text contains (parseable fields)

From the source code, the eval text has these exact literal patterns: raw.githubusercontent

```
=== GENERAL INFORMATION ===
Final evaluation: <N> (Win Probability: <N>%)
Shashin Zone: <zone>
Game Phase: <phase>

  ELEMENT        |    MG      EG   Total
  ---------------+--------------------
  Mobility       | ...
  Space          | ...
  ...

=== MOBILITY SUBELEMENTS ===
Mobility by area based on the Kasparov Principle:
  White: Queen Side(<N>) Center(<N>) King Side(<N>)
  Black: Queen Side(<N>) Center(<N>) King Side(<N>)
  Difference (White-Black): Queen Side(<N>) Center(<N>) King Side(<N>)

=== SPACE SUBELEMENTS ===
Space Detail by Area:
     Queen side  Center  King side
White         <N>    <N>    <N>
Black         <N>    <N>    <N>
Difference White-Black <N>  <N>  <N>
Total Space: White <N> - Black <N>

Weak Squares (not defended by pawns):
White: <sq1> <sq2> ...
Black: <sq1> <sq2> ...

FINAL SUMMARY
Unit Ranking by static activity (Makogonov Principle) - Worst to Best:
White: N<sq>(<N>), B<sq>(<N>), ...
Black: N<sq>(<N>), B<sq>(<N>), ...
Makogonov White: Improve <piece> on <sq> (activity: <N>)
Makogonov Black: Improve <piece> on <sq> (activity: <N>)
```

## The Parser — `alexander_anomaly_detector.py`

```python
import re
from dataclasses import dataclass, field
from typing import Optional

# ── Thresholds (tune empirically on test positions) ──────────────────────────
MOBILITY_AREA_IMBALANCE   = 4   # per-area mobility gap triggering anomaly
MOBILITY_TOTAL_IMBALANCE  = 10  # total mobility gap
SPACE_TOTAL_IMBALANCE     = 6   # total space gap
SPACE_AREA_IMBALANCE      = 4   # single-area space gap
WEAK_SQ_COUNT_THRESHOLD   = 6   # weak squares per side in middlegame
ACTIVITY_LOW_THRESHOLD    = 5   # Makogonov worst-piece activity below this
ACTIVITY_MAJOR_THRESHOLD  = 8   # if major piece is worst AND score below this
EVAL_CP_SURPRISE          = 80  # eval in cp far from what structure implies


@dataclass
class EvalSnapshot:
    """All structured data extracted from one Alexander eval text block."""
    eval_cp:        Optional[int]   = None
    win_prob:       Optional[int]   = None
    shashin_zone:   Optional[str]   = None
    game_phase:     Optional[str]   = None   # "Middlegame", "Endgame", etc.

    # Mobility by area  {color: {area: count}}
    mobility: dict = field(default_factory=dict)
    mobility_diff: dict = field(default_factory=dict)   # {area: w-b}

    # Space
    space: dict = field(default_factory=dict)           # {color: {area: val}}
    space_total: dict = field(default_factory=dict)     # {color: int}

    # Weak squares (as raw string tokens, e.g. ["e5","d6"])
    weak_squares: dict = field(default_factory=dict)    # {color: [sq,...]}

    # Makogonov worst piece per side
    worst_piece: dict = field(default_factory=dict)     # {color: (piece, sq, score)}
    # Full Makogonov ranking per side (list of (symbol, sq, score) worst→best)
    ranking: dict = field(default_factory=dict)


def parse_eval_text(text: str) -> EvalSnapshot:
    snap = EvalSnapshot()

    # ── General info ─────────────────────────────────────────────────────────
    m = re.search(r'Final evaluation:\\s*(-?\\d+)', text)
    if m: snap.eval_cp = int(m.group(1))

    m = re.search(r'Win Probability:\\s*(\\d+)%', text)
    if m: snap.win_prob = int(m.group(1))

    m = re.search(r'Shashin Zone:\\s*(.+)', text)
    if m: snap.shashin_zone = m.group(1).strip()

    m = re.search(r'Game Phase:\\s*(.+)', text)
    if m: snap.game_phase = m.group(1).strip()

    # ── Mobility by area ─────────────────────────────────────────────────────
    # "  White: Queen Side(3) Center(5) King Side(2)"
    for color in ('White', 'Black'):
        pat = rf'{color}:\\s+Queen Side\\((-?\\d+)\\)\\s+Center\\((-?\\d+)\\)\\s+King Side\\((-?\\d+)\\)'
        m = re.search(pat, text)
        if m:
            snap.mobility[color] = {
                'Queen Side': int(m.group(1)),
                'Center':     int(m.group(2)),
                'King Side':  int(m.group(3)),
            }

    m = re.search(
        r'Difference \\(White-Black\\):\\s+Queen Side\\((-?\\d+)\\)\\s+Center\\((-?\\d+)\\)\\s+King Side\\((-?\\d+)\\)',
        text)
    if m:
        snap.mobility_diff = {
            'Queen Side': int(m.group(1)),
            'Center':     int(m.group(2)),
            'King Side':  int(m.group(3)),
        }

    # ── Space ────────────────────────────────────────────────────────────────
    # "White          <N>    <N>    <N>"  (after "Space Detail by Area:")
    space_section = re.search(
        r'Space Detail by Area:.*?(?=\\n\\n|\\Z)', text, re.DOTALL)
    if space_section:
        sec = space_section.group(0)
        for color in ('White', 'Black'):
            m = re.search(rf'^{color}\\s+(\\d+)\\s+(\\d+)\\s+(\\d+)', sec, re.MULTILINE)
            if m:
                snap.space[color] = {
                    'Queen Side': int(m.group(1)),
                    'Center':     int(m.group(2)),
                    'King Side':  int(m.group(3)),
                }
        # "Total Space: White 12 - Black 8"
        m = re.search(r'Total Space:\\s+White\\s+(\\d+)\\s+-\\s+Black\\s+(\\d+)', sec)
        if m:
            snap.space_total = {'White': int(m.group(1)), 'Black': int(m.group(2))}

    # ── Weak squares ─────────────────────────────────────────────────────────
    # "White: e5 d6 f4 \\nBlack: d4 c5"
    ws_section = re.search(
        r'Weak Squares \\(not defended by pawns\\):\\n'
        r'White:\\s*(.*?)\\n'
        r'Black:\\s*(.*?)\\n',
        text)
    if ws_section:
        def parse_sq_list(s):
            tokens = s.strip().split()
            return [t for t in tokens if re.match(r'[a-h][1-8]', t)]
        snap.weak_squares['White'] = parse_sq_list(ws_section.group(1))
        snap.weak_squares['Black'] = parse_sq_list(ws_section.group(2))

    # ── Makogonov ranking ─────────────────────────────────────────────────────
    # "White: Nc3(12), Bd4(18), Rf1(24)"
    # "Makogonov White: Improve Knight on c3 (activity: 12)"
    for color in ('White', 'Black'):
        # worst piece line
        m = re.search(
            rf'Makogonov {color}:\\s+Improve\\s+(\\w+)\\s+on\\s+([a-h][1-8])\\s+\\(activity:\\s*(-?\\d+)\\)',
            text)
        if m:
            snap.worst_piece[color] = (m.group(1), m.group(2), int(m.group(3)))

        # full ranking line: "White: Na3(5), Bg2(18), ..."
        m = re.search(rf'^{color}:\\s+((?:[A-Z][a-h][1-8]\\(-?\\d+\\),?\\s*)+)', text,
                      re.MULTILINE)
        if m:
            entries = re.findall(r'([A-Z])([a-h][1-8])\\((-?\\d+)\\)', m.group(1))
            snap.ranking[color] = [(sym, sq, int(sc)) for sym, sq, sc in entries]

    return snap


# ── Anomaly rules ─────────────────────────────────────────────────────────────

MAJOR_SYMBOLS = {'R', 'Q'}

def _count_weak(snap: EvalSnapshot, color: str) -> int:
    return len(snap.weak_squares.get(color, []))

def detect_anomalies(snap: EvalSnapshot) -> list[str]:
    """
    Returns a list of anomaly strings.
    Empty list = no anomalies detected.
    Only fires on Middlegame phase; returns [] otherwise.
    """
    if not snap.game_phase or 'Middlegame' not in snap.game_phase:
        return []

    anomalies = []

    # ── M1: Mobility imbalance per area ──────────────────────────────────────
    for area, diff in snap.mobility_diff.items():
        if abs(diff) >= MOBILITY_AREA_IMBALANCE:
            weaker = 'White' if diff < 0 else 'Black'
            anomalies.append(
                f"[M1] {weaker} mobility deficit in {area}: "
                f"gap={abs(diff)} (W={snap.mobility.get('White',{}).get(area,'?')} "
                f"B={snap.mobility.get('Black',{}).get(area,'?')})"
            )

    # ── M2: Total mobility severely lopsided ─────────────────────────────────
    if snap.mobility.get('White') and snap.mobility.get('Black'):
        wt = sum(snap.mobility['White'].values())
        bt = sum(snap.mobility['Black'].values())
        if abs(wt - bt) >= MOBILITY_TOTAL_IMBALANCE:
            weaker = 'White' if wt < bt else 'Black'
            anomalies.append(
                f"[M2] Total mobility severely imbalanced: White={wt} Black={bt} "
                f"— {weaker} side is engine-suspect for passivity"
            )

    # ── S1: Space total imbalance ─────────────────────────────────────────────
    if snap.space_total:
        wsp = snap.space_total.get('White', 0)
        bsp = snap.space_total.get('Black', 0)
        diff = wsp - bsp
        if abs(diff) >= SPACE_TOTAL_IMBALANCE:
            weaker = 'White' if diff < 0 else 'Black'
            anomalies.append(
                f"[S1] Space total imbalance: White={wsp} Black={bsp} "
                f"— {weaker} is cramped; watch for middlegame misevaluation"
            )

    # ── S2: Per-area space collapse (one side dominates single area entirely) ──
    if snap.space.get('White') and snap.space.get('Black'):
        for area in ('Queen Side', 'Center', 'King Side'):
            wv = snap.space['White'].get(area, 0)
            bv = snap.space['Black'].get(area, 0)
            if abs(wv - bv) >= SPACE_AREA_IMBALANCE:
                weaker = 'White' if wv < bv else 'Black'
                anomalies.append(
                    f"[S2] {weaker} space collapse in {area}: "
                    f"W={wv} B={bv}"
                )

    # ── W1: Excessive weak squares ────────────────────────────────────────────
    for color in ('White', 'Black'):
        n = _count_weak(snap, color)
        if n >= WEAK_SQ_COUNT_THRESHOLD:
            anomalies.append(
                f"[W1] {color} has {n} weak squares in middlegame "
                f"({', '.join(snap.weak_squares[color])}) "
                f"— pawn structure severely compromised"
            )

    # ── A1: Worst piece critically passive ────────────────────────────────────
    for color in ('White', 'Black'):
        wp = snap.worst_piece.get(color)
        if wp:
            piece_name, sq, score = wp
            if score <= ACTIVITY_LOW_THRESHOLD:
                anomalies.append(
                    f"[A1] {color} worst piece ({piece_name} on {sq}) "
                    f"activity={score} — critically passive in middlegame"
                )

    # ── A2: Major piece is worst in middlegame (structural inconsistency) ─────
    for color in ('White', 'Black'):
        ranking = snap.ranking.get(color, [])
        if ranking:
            sym, sq, score = ranking[0]  # worst = first after sort
            if sym in MAJOR_SYMBOLS and score <= ACTIVITY_MAJOR_THRESHOLD:
                anomalies.append(
                    f"[A2] {color} major piece ({sym}{sq}, activity={score}) "
                    f"is worst in middlegame — rook/queen severely restricted; "
                    f"check open file access"
                )

    # ── C1: Shashin zone contradicts eval score ───────────────────────────────
    if snap.shashin_zone and snap.eval_cp is not None:
        zone = snap.shashin_zone.lower()
        cp   = snap.eval_cp
        # Tal zone should have strong positive/negative eval, not near-equal
        if 'tal' in zone and abs(cp) < 20:
            anomalies.append(
                f"[C1] Shashin zone is '{snap.shashin_zone}' but eval={cp}cp "
                f"— zone/score contradiction; engine may be over-optimistic"
            )
        # Petrosian (losing) zone should not have near-zero eval
        if 'petrosian' in zone and abs(cp) < 15:
            anomalies.
